# Tabla-de-amortizacion-POO
Este proyecto consiste en una aplicación de consola desarrollada en C# utilizando Programación Orientada a Objetos (POO), la cual permite calcular y mostrar una tabla de amortización de un préstamo con cuotas fijas. El sistema valida los datos ingresados por el usuario y genera un cronograma de pagos detallado de manera organizada en la consola.
